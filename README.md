# 英语角 · English Corner

面向中文学习者的英语练习站。使用 Vue 3、Vite 和 Vue Router，教材随站点分发，进度、错题、主题和作文草稿保存在当前浏览器。

| 模块 | 功能与内容 |
| --- | --- |
| 首页 | 60 条每日一句，首次学习引导、今日目标、连续学习、本周统计与续学 |
| 单词 | 400 词，CET-4、CET-6、IELTS、日常高频各 100 词。支持本地发音、翻卡、闪卡、掌握度、双向四选一、听音与看释义拼写、错题重练及词库搜索 |
| 听力 | A2 至 C1 共 20 篇，每级 5 篇。支持播放、暂停、进度定位、四档倍速和原文显隐，共 80 道理解题、100 个听写空 |
| 阅读 | A2 至 C1 共 12 篇，每级 3 篇。含 72 条文内生词、60 道理解题，支持生词释义、收藏、加入错题本和阅读用时记录 |
| 写作 | 16 个模板（CET 6 个、IELTS Task 1 6 个、Task 2 4 个）、21 道练习题。含写作框架、双语表达、范文、实时词数、计时、句型插入、自动保存、删除草稿和交卷自评 |
| 语法 | 12 节小课，配讲解、双语例句、易错点与 60 道随堂小测 |
| 表达 | 8 个场景、60 条常用表达，均有双语例句和录音 |
| 我的与全站 | 学习进度、错题、收藏、作文、JSON 导出和确认清除。支持全站搜索、浅色与深色模式、桌面导航与移动底栏 |

## 本地运行

需要 Node.js 20.19+ 或 22.12+。首次安装依赖时需要访问 npm，已构建的站点从同一站点地址读取代码和音频。

```sh
npm ci
npm run dev
```

## 构建和部署

```sh
npm run build
npm run preview
```

将 `dist/` 的内容作为 GitHub Pages artifact 部署，或将其内容提交到选作 Pages 发布源的分支根目录。构建会复制 `.nojekyll`。资源基址是 `./`，Vue Router 使用 hash 路由，仓库子路径中的阅读详情链接形如 `/仓库名/#/reading/文章ID`。

## 数据与音频

- `src/data/` 存放词库、教材、练习、每日例句和单词音频映射。
- `public/audio/` 存放 480 个预生成的 MP3（单词 400 个、听力 20 个、表达 60 个），构建后原样复制到 `dist/audio/`。词库音标采用英式 IPA，录音使用 Piper 的美式 Lessac 模型。
- 浏览器通过本地站点路径播放 MP3。写作练习采用检查表自评。
- 改动文本后，删除对应的旧 MP3 再重生成。脚本默认跳过已有的非空文件，并报告失败文件。

```sh
python3 scripts/gen_audio.py
python3 scripts/gen_audio.py listening --jobs 3
```

重生成需要 Piper、Lessac 模型及其 JSON 配置和 FFmpeg。Piper 与模型默认从工作区相邻的 `tools/` 目录读取，可通过 `--piper` 与 `--model` 或 `PIPER_BIN` 与 `PIPER_MODEL` 指定。播放已生成的站点只需静态 HTTP 托管。

## 内容校验

运行 `python3 scripts/check_content.py` 可核对测验答案索引、听写原文、阅读生词、写作范文词数和本地音频引用。构建与页面走查结果见 [BUILD_REPORT.md](BUILD_REPORT.md)。
